# Next construction levels — Remember the Seasons

Methodology: destination-driven construction. The destination is named
first; every level below is a coherent state of THAT product — not a
feature, not a prototype, not an approximation. When time runs out we
stop at the highest coherent level reached; we do not ship thin
versions of everything.

## Destination

A personal agent memory that **behaves** on compact adaptive state,
**explains** on a verifiable forensic trajectory, and **proves**
causal relevance by replaying the world without a transition — usable
as a real PKM and as an MCP tool any agent can plug into.

The load-bearing invariants every level inherits from level 1:
deterministic core (exact arithmetic, canonical seals), LLM outside
the decision path, write-nothing inspection, authority-at-time, sealed
evidence over narrative. These are not a later "hardening" level —
they are the entry price of every level.

## Level map

```
L1 forensic field      → custody chains, receipts, decisions, bundles
L2 causal inspection   → trajectory + decision counterfactual
L3 PKM surface         → vault, links, supersession, forget, CLI
L4 channel integrity   → served≠used≠reinforced + Kassandra tripwire
L5 consumable surface  → CLI / UI / MCP, hosted, persistent
L6 verified ops        → benchmarks, embedding index, deploy evidence
L7 shared field        → stigmergy axis: multi-agent shared state
L8 global rewind       → do(T=0) over the full causal trajectory
```

## Gates

**L5 close:** demo reachable over HTTPS on Nebius AI Cloud; the same
`seasons.db` survives restarts; a non-local user can ask, see the
seasons, excise a transition and read the delta — without touching
the host.

**L6 close:** embedding index keeps recall sub-100ms at 10k notes
WITHOUT changing ranking semantics (the index is an optimization of
the same scoring — a differential test must prove identical served
sets before/after); a live Nebius run captured end-to-end as evidence.

**L7 open correctly:** the STIGMERGY question is NOT "demonstrate
emergence" — Exp H10 was falsified. The gate: two agents with separate
authority share a field; can each reconstruct what shared state
conditioned its decisions, no direct messages, no authority mixing?
The falsified collective claim stays falsified in the docs.

**L8 open correctly:** `do(T_i=0)` must rewind the transition's
propagated effects — decisions that cited it, reinforcements it
enabled, links it traversed — or the report must name exactly which
consequences it could NOT unwind. No silent partial rewinds.

## Non-negotiables

- No level gets called built on a demo. Gates close on evidence.
- Under deadline: fewer levels, fully built — never all of them thin.
- The falsified claims (collective contagion, scalar sufficiency)
  stay falsified in every doc. The repo's credibility is the product.
